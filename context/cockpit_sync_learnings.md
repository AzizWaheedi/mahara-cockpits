- Tool-side gotchas seen repeatedly: (1) `wait_for_background_work` can itself time out (~60s) while the script keeps running fine for 100-300s — just re-wait, not a script failure. (2) foreground `bash uv run` (even under shell `timeout N`) gets killed by the bash tool's own 60s job limit before the script finishes, producing a misleading "Command timed out"/exit_code -1. Workaround: launch via `nohup uv run python … > /tmp/log 2>&1 &`, capture PID, then `wait_for_background_work` with `wake_condition_command: "! kill -0 <pid>"`, then read the log file.

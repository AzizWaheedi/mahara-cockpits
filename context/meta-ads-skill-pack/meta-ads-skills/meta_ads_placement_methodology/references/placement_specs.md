# Complete Creative Specifications by Meta Placement

## Purpose

Definitive reference for creative specifications across every Meta Ads placement. Includes pixel dimensions, file sizes, character limits, and format requirements. Use this when building creative assets or auditing existing ads for placement compatibility.

## Cross-Placement Creative Matrix

Quick reference for which formats work across which placements:

| Creative Format | FB Feed | FB Stories | FB Reels | IG Feed | IG Stories | IG Reels | Right Col | Marketplace | AN | Messenger |
|----------------|---------|-----------|---------|---------|-----------|---------|-----------|------------|-----|----------|
| 1:1 Static | Yes | Letterbox | No | Yes | Letterbox | No | Yes | Yes | Yes | Yes |
| 4:5 Static | Yes | Letterbox | No | Yes | Letterbox | No | No | Yes | No | No |
| 9:16 Static | Letterbox | Yes | No | Letterbox | Yes | No | No | No | Yes | Yes |
| 1:1 Video | Yes | Letterbox | No | Yes | Letterbox | No | No | Yes | Yes | No |
| 4:5 Video | Yes | Letterbox | No | Yes | Letterbox | No | No | Yes | No | No |
| 9:16 Video | Pillarbox | Yes | Yes | Pillarbox | Yes | Yes | No | No | Yes | Yes |
| 16:9 Video | Yes | Letterbox | No | Yes | Letterbox | No | No | Yes | Yes | No |

**Key:**
- "Yes" = native fit, optimal display
- "Letterbox" = black bars top/bottom (content doesn't fill the screen)
- "Pillarbox" = black bars left/right (content doesn't fill the width)
- "No" = format not supported for this placement

## Minimum Creative Set for Full Coverage

To serve ads effectively across all placements with no letterboxing:

| Asset | Dimensions | Placements Covered |
|-------|-----------|-------------------|
| 1:1 Static Image | 1200x1200px | FB Feed, IG Feed, Right Column, Marketplace, Messenger, AN |
| 4:5 Static Image | 1080x1350px | FB Feed (max real estate), IG Feed |
| 9:16 Static Image | 1080x1920px | FB Stories, IG Stories, Messenger Stories |
| 1:1 Video (15-30s) | 1080x1080px | FB Feed, IG Feed, Marketplace |
| 9:16 Video (15-30s) | 1080x1920px | FB Stories, IG Stories, FB Reels, IG Reels |

This 5-asset set provides native coverage for all major placements. For Advantage+ Placements campaigns, this set ensures Meta can deliver without quality loss on any placement.

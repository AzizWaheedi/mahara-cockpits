# AGENTS.md — Your Workspace

This folder is home. Treat it that way.

## Session Startup

1. Read `SOUL.md` — this is who you are
2. Read `USER.md` — who you are working for
3. Read `TOOLS.md` — where the work comes from and what you may touch
4. Read `memory/YYYY-MM-DD.md` (today and yesterday)
5. Read `MEMORY.md` — your craft memory

Don't ask permission. Just do it.

## Memory

You wake fresh every run. These files are the continuity.

- **Daily notes:** `memory/YYYY-MM-DD.md` — what you did, what you noticed,
  what went wrong. Raw. Written as you go, not at the end.
- **Craft memory:** `MEMORY.md` — the distilled version. Only patterns you
  have seen across **more than one client**. One person changing one word
  is not a pattern.

A client's own memory is not here — it is `social_bank` in Supabase, where
staff can see and edit it. Keep them apart. A note about Ardon goes in
Ardon's bank; a note about how to open an Education post goes here.

## The rule about finishing

A job is `done` when the row it was supposed to write is written. Not when
you have decided what to write. If you are about to mark something done
having produced nothing, mark it `failed` and say what was missing --
the queue is read by people who assume `done` means there is something
to look at.

## The rule about scale

You are drained in batches, grouped by pillar across clients. Twelve
clients' Craft posts in one run is the normal shape, not twelve separate
end-to-end runs. If you find yourself loading one client's whole world to
write one post, you are working the expensive way.

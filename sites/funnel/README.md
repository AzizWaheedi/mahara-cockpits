# funnel.maharamedia.com

Mahara's main lead funnel (VSL page, booking, thank-you pages, offer explainer) and the
case-study, testimonial and legal pages that ads and the funnel link to. Moved off
GoHighLevel on 2026-11-07. Vercel project `mahara-main-funnel`
(team `team_CYujeiq6dPtfcUEHS14lcJuV`), served as static files.

`site/` is what is live. It is generated by `build.py` from `src/` and committed, images
included, so a rebuild never needs GHL.

## Changing a page

- Custom-code pages: edit the file in `src/` (`home.html` is the VSL page).
- GHL-built pages (booking, case studies, legal): edit their text in `src/native-pages.json`;
  the templates are `booking_page`, `case_page` and `terms_page` in `build.py`.
- Then build and check the page in `site/`:

```bash
python3 build.py
```

`build.py` needs Python 3 and Pillow (only for new images). Things it does to every
custom-code page, because the pages were designed inside GHL:
- adds `line-height: normal` on the page wrapper (GHL's wrapper set it; without it bars and
  buttons grow ~8px) and `overflow-x: clip` on the root;
- adds 40px to the home hero's top padding (GHL put 40px of wrapper above the code);
- moves inline base64 images into `site/assets/img/`, copies GHL-hosted images into
  `site/assets/`, loads Google Fonts without blocking, and loads the Elfsight reviews widget
  only when its section is near the screen.

## Deploy

From a commit that is on GitHub main:

```bash
cd sites/funnel
python3 build.py
cd site && vercel deploy --prod
```

`site/.vercel/project.json` is not in git:
`{"projectId":"prj_XAr8EkGWJMuTo6WZZCJLrSmK3SEi","orgId":"team_CYujeiq6dPtfcUEHS14lcJuV","projectName":"mahara-main-funnel"}`
(or `vercel link --yes --project mahara-main-funnel` from `site/`; `.vercelignore` keeps the
`.env.local` it writes out of the upload). Then check the live page, e.g.
`curl -s https://funnel.maharamedia.com/ | grep -c "fbq('track','PageView')"` → `1`.
